# Yande.re 推图

这是 daily-art 1.7.0 或以上的配套模块。把本目录复制到 Aurabot 数据目录的 `modules/daily-art-yandere`，与 `modules/daily-art` 并列。加载后，在「系统 → Yande.re 推图」配置时间、张数、白名单、筛选条件和代理。

定时推送默认关闭，白名单默认为空。QQ 按需找图使用「yande找图」，例如「yande找图 初音未来，先列候选」。定时与按需查询仅选择 Safe（`s`）作品。元数据请求访问 `yande.re`，图片可能来自 `files.yande.re`。可在配置页检测 API 和样图下载，在日志中搜索 `[Yande.re]`。
